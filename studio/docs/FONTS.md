# Typography & Font Library

The design studio provides a diverse collection of open-source TrueType font styles licensed under the **SIL Open Font License 1.1**. All static `.ttf` binaries are placed in `assets/fonts/` and `studio/assets/fonts/` for offline deterministic rendering.

## Available Font Styles & Aesthetic Archetypes

If an organizer rejects a particular design aesthetic, select one of the distinct typography archetypes below:

| Font Archetype | Heading Font File | Body Font File | Vibe & Ideal Use Case |
| :--- | :--- | :--- | :--- |
| **1. Modern Clean (Default)** | `Inter-Bold.ttf` | `Inter-Regular.ttf` | Corporate, neutral, high-legibility Silicon Valley tech aesthetic. |
| **2. Friendly Geometric** | `Poppins-Bold.ttf` | `Poppins-Regular.ttf` | Approachable, rounded circular geometry, collegiate hackathons. |
| **3. Cyber / Monospace** | `SpaceGrotesk-Bold.ttf` | `Inter-Regular.ttf` | Edgy, monospaced-adjacent, algorithmic hackathons & CTFs. |
| **4. Modular Indian Tech** | `Rajdhani-Bold.ttf` | `Rajdhani-Regular.ttf` | Condensed, squared tech sans (Indian Type Foundry). **Best for long names** (fits 25% more characters without clipping). |
| **5. High-Impact Condensed** | `BebasNeue-Regular.ttf` | `Inter-Regular.ttf` | All-caps, punchy, compact athletic/display header. |
| **6. Futuristic Sci-Fi** | `ChakraPetch-Bold.ttf` | `ChakraPetch-Regular.ttf` | Angular, high-tech, robotics & gaming/esports hackathons. |
